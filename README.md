# Plateforme de Formation - SQL

Projet réalisé dans le cadre de ma formation en Développement Data a la Sonatel Academy.

## Objectifs

Ce projet consiste à :

- Concevoir une base de données relationnelle
- Modéliser les entités et relations
- Implémenter la base en SQL
- Réaliser des requêtes SQL avancées
- Traduire des requêtes en algèbre relationnelle

## Technologies utilisées

- MySQL
- SQL
- Algèbre relationnelle

## Modèle de données

### Entités principales

- Classes
- Apprenants
- Modules
- Inscriptions
- Notes

## Compétences démontrées

- Modélisation relationnelle
- Clés primaires et étrangères
- Jointures
- Agrégations
- Sous-requêtes
- UNION
- Division relationnelle
- Analyse métier
